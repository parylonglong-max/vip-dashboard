# 品牌视角数据口径 V1.0

## 信息架构

- 一级维度：小组视角 / 品牌视角。
- 小组视角保留现有业务模块；品牌视角使用独立二级业务导航。
- 品牌搜索上下文在品牌模块间复用，品牌 SN 是唯一标识。

## 品牌调价率

数据源：《【业绩】小组销售看板_精品》附件。

- 品牌目录与属性：`brand_info`。
- 品牌调价原始计数：`data` 与 `data非神银`，先清洗为标准日明细 `brand_adjustment_daily.json`。
- 筛选条件：`数据分组=TOTAL`、`辅助列3=cur`、当前数据月。
- 标准层聚合键：品牌SN + 日期；前端月历再按品牌SN读取每日明细。
- `brand_info` 仅用于品牌目录、等级、小组、神银标签补全，不参与指标伪造。
- 价高商品：汇总 `BK 价高商品数`。
- 调价商品数：汇总 `BL 价高调价商品数`。
- 调价率：调价商品数 ÷ 价高商品数。
- 有明细但分母为0：价高数/调价数显示 `0`，调价率显示 `—`；没有任何日明细：三个指标均显示 `—`。两者均不得判断为未达标。
- 目标：75%；低于目标使用红色数值与轻量“未达标”标识。

品牌 `TOTAL` 分组与小组汇总覆盖范围不同，不进行跨粒度总量强行对平。发布时必须校验：两张来源表均已纳入、来源品牌SN无重叠、标准层SN+日期唯一、调价数不大于价高数、品牌月度汇总等于日明细之和、前端JSON总数等于标准层总数。

## 搜索

支持品牌中文/英文名称和 SN 的模糊搜索，排序优先级：

1. SN 完全匹配；
2. 品牌名完全匹配；
3. SN 前缀；
4. 品牌名前缀；
5. SN/品牌名包含。

候选最多展示8条，并展示品牌等级和神银标签。
