# 品牌视角数据口径 V1.0

## 信息架构

- 一级维度：小组视角 / 品牌视角。
- 小组视角保留现有业务模块；品牌视角使用独立二级业务导航。
- 品牌搜索上下文在品牌模块间复用，品牌 SN 是唯一标识。

## 品牌调价率

数据源：《【业绩】小组销售看板_精品》附件。

- 品牌目录与属性：`brand_info`。
- 品牌调价原始计数：`data`。
- 筛选条件：`数据分组=TOTAL`、`辅助列3=cur`、当前数据月。
- 聚合键：品牌 SN；同一 SN 跨小组时合并原始计数。
- 价高商品：汇总 `BK 价高商品数`。
- 调价商品数：汇总 `BL 价高调价商品数`。
- 调价率：调价商品数 ÷ 价高商品数。
- 分母为0：显示 `—`，不得判断为未达标。
- 目标：75%；低于目标使用红色数值与轻量“未达标”标识。

品牌 `TOTAL` 分组与小组汇总覆盖范围不同，不进行跨粒度总量强行对平。发布时只校验品牌内部原始计数、比率重算和 SN 唯一性。

## 搜索

支持品牌中文/英文名称和 SN 的模糊搜索，排序优先级：

1. SN 完全匹配；
2. 品牌名完全匹配；
3. SN 前缀；
4. 品牌名前缀；
5. SN/品牌名包含。

候选最多展示8条，并展示品牌等级和神银标签。
